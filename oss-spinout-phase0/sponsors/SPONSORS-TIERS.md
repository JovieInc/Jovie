# GitHub Sponsors — Tier Ladder & Profile Prep (Phase 0)

Decision-ready. Owner: Summer. Status: DRAFT (needs Tim sign-off + bank/tax).

## Profile setup
- Sponsors on a **PERSONAL/individual profile** (0% platform fee — 100% passes through).
- NOT the `jovie` org (org sponsorships carry up to 6% fee).
- Required: complete profile, tiers created, bank + tax info, 2FA enabled.

## Tier ladder (per flagship repo)
| Tier | Price | Perk |
|------|-------|------|
| Supporter ("saint") | $7/mo | No perks, just thanks — anchor ABOVE $1–5 |
| Builder | $14–19/mo | Sponsor-only changelog + roadmap + early access |
| Pro / Early-Access (Sponsorware) | $49/mo | Early access to next Sponsorware feature before open-source |
| Org / Partner | $99–499/mo | Logo in docs + light monthly consulting slot |

## Sponsorware model
- Build features EXCLUSIVELY for sponsors, announce, open-source after a public sponsor threshold.
- Transparency of progress toward threshold drives conversion.
- 2–4x better than donation CTA (Caleb Porzio: $573→$1,560/mo in 2 days).

## Realistic expectations
- First sponsorship: within 1–2 launches (if repo visible + Sponsorware active).
- First dollar: week 6–10.
- First $500/mo: month 3–6 (breakout — one repo threshold + 2–3 org sponsors).
