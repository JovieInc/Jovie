# Add a release manually

<HelpOutcome>
Create a release in Jovie by hand when it is not imported from a streaming
platform.
</HelpOutcome>

<HelpPrerequisites>

- A Jovie account with the manual release creation capability on your plan.

</HelpPrerequisites>

<HelpSteps>

<HelpStep title="Open Releases">
From your dashboard, go to **Releases**.
</HelpStep>

<HelpStep title="Select New release">
Choose **New release** at the top of the release list.
</HelpStep>

<HelpStep title="Enter the release details">
Fill in the title and primary artist name exactly as they appear on the
release.
</HelpStep>

<HelpStep title="Save the release">
Confirm the details and save. Jovie creates the release and its smart link.

<HelpScreenshot
  src="/proof/add-a-release-manually-new-release.png"
  alt="The Releases view with the New release action and the release details form"
  caption="The Releases view after selecting New release."
/>
</HelpStep>

</HelpSteps>

## What happens next

The release appears in **Releases** with a smart link you can share. Open the
release to review or edit its links.

<HelpTroubleshooting>

### The New release action is missing

Manual release creation is plan-gated. Check your plan under **Settings →
Billing**, or contact support.

### The release does not appear after saving

Refresh **Releases**. If it is still missing, save again and contact support
if the problem continues.

</HelpTroubleshooting>
