# Edit and Share a Smart Link

<HelpOutcome>Update a smart link's title and artwork from the Links screen and copy its public URL to share.</HelpOutcome>

Every release on Jovie gets a smart link — one URL that routes fans to their
preferred music service. You can update the link's title and artwork at any
time from the **Links** screen in your dashboard.

<HelpSteps>

<HelpStep title="Open your Links screen">
In the dashboard sidebar, choose **Links**. Each row is one smart link: the
release title, artwork, and the public URL fans visit.

<HelpScreenshot src="/proof/edit-smart-link-links-dashboard.png" alt="The Links screen in the Jovie dashboard listing smart links for the example artist." caption="Each row is one smart link." />
</HelpStep>

<HelpStep title="Open the link for editing">
Select the smart link you want to update. The link opens so you can change
the title, artwork, and which services are featured.

<HelpScreenshot src="/proof/edit-smart-link-open-link-editor.png" alt="A smart link row expanded in the Links screen showing the editable fields." caption="Edit title, artwork, and featured services." />
</HelpStep>

<HelpStep title="Copy and share the public URL">
Copy the public URL shown on the link. When fans open it on a phone, the
page renders at mobile size with your featured services first.

<HelpScreenshot src="/proof/edit-smart-link-public-page-mobile.png" alt="The public smart link page for the example artist rendered at phone size." caption="Copy the public URL to share." />
</HelpStep>

</HelpSteps>

## What happens next

Changes take effect immediately on the public page — no need to reshare the
URL.
