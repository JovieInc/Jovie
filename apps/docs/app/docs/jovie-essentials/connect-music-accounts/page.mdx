# Connect Spotify, Apple Music, or YouTube

Music connections live in **Library → Releases**, not in Settings. Each provider has its own connect control:

- **Spotify** — use `Connect Spotify` in Library to link your artist account and auto-import releases.
- **Apple Music** — connect Apple Music from the same Releases view.
- **YouTube** — use `Import YouTube` in Library to pull in your channel releases.

There is no single authorization that covers all three providers; connect each one you use.
