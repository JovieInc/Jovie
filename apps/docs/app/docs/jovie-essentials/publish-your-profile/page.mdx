# Publish your profile

A Jovie profile goes public once it is claimed and complete enough to publish — there is no standalone `Public` toggle.

- Finish onboarding at [jov.ie/start](https://jov.ie/start) and complete the required profile fields.
- Once publishable, your profile is live at `jov.ie/yourname`.
- If something blocks publication, complete the remaining onboarding steps first, then check [troubleshooting](/docs/manage-jovie/troubleshooting).
