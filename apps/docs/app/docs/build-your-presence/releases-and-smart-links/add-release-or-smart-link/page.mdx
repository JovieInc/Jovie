# Add a release or create its link

Manage releases from **Library → Releases** (`/app/library?view=releases`).

- Import releases by connecting Spotify, Apple Music, or YouTube, or add a release manually in Library.
- Open a release and use `Copy Link` to copy its smart link for sharing.
