# Add a release or create its link

<HelpOutcome>
Get a release into your Jovie library and copy the smart link fans use to
listen on their own service.
</HelpOutcome>

<HelpPrerequisites>

- A Jovie account with a claimed profile.
- For manual creation, the manual release capability on your plan.

</HelpPrerequisites>

<HelpSteps>

<HelpStep title="Open Library → Releases">
From your dashboard, open **Library** and select the **Releases** view
(`/app/library?view=releases`).
</HelpStep>

<HelpStep title="Import from a music account">
With no releases yet, choose **Connect Spotify** to import your catalog.
Once Spotify is connected, the header shows **Sync from Spotify** to pull in
new releases. Jovie matches each release to other music services
automatically.
</HelpStep>

<HelpStep title="Or add the release manually">
Choose **New release** in the Releases header to open the **Add release**
panel. Enter the **Title** (required), **Release Type**, **Release Date**,
and optional **Reveal Date**, **Genres**, **Explicit** marker, and artwork —
then select **Create Release**.

<HelpScreenshot
  src="/proof/add-release-or-smart-link-library.png"
  alt="The Releases view in Library with the New release action and the Add release panel showing Title, Release Type, and Release Date"
  caption="The Add release panel in Library → Releases."
/>
</HelpStep>

<HelpStep title="Copy the smart link">
Open the release in Library and use its copy-link control to copy the smart
link — with or without UTM tracking. The public release page lives at
`jov.ie/yourname/release-name` and lists each available music service.
</HelpStep>

</HelpSteps>

## What happens next

The release appears in **Releases** and on your public profile. Share the
smart link anywhere — fans pick their own service on the release page.

<HelpTroubleshooting>

### A release is missing from Library

Select **Sync from Spotify** to refresh the import. If the release still does
not appear — for example it is not on Spotify yet — create it with **New
release** instead.

### A smart link points at the wrong service or page

Open the release in Library and check its details and linked services. Fix
the release data and copy the link again; if a matched destination is wrong,
contact support to correct it.

</HelpTroubleshooting>
