# Releases and smart links

Releases live in **Library → Releases** (`/app/library?view=releases`).

- [Add a release or create its link](/docs/build-your-presence/releases-and-smart-links/add-release-or-smart-link) — import from a connected provider or add one manually, then copy its smart link.
- Connect providers first via [Connect Spotify, Apple Music, or YouTube](/docs/jovie-essentials/connect-music-accounts).
