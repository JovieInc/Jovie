# Edit your name, bio, images, and links

Profile editing lives at **Settings → Artist Profile** (`/app/settings/artist-profile`).

- The sidebar section is `Artist Profile`; the page is `Artist` with a `Profile` panel.
- Use `Links, music & more` to manage the links shown on your public page.
- Use `View as Visitor` to preview the public result before sharing.
