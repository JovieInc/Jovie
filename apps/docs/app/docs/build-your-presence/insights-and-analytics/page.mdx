# Insights and analytics

Insight cards live at `/app/insights` and summarize visits and audience trends.

- Audience-level detail stays on the [Audience](/docs/build-your-presence/audience) tab in Contacts.
- There is no separate `/dashboard/analytics` page; use Insights for cards and Audience for fan-level data.
